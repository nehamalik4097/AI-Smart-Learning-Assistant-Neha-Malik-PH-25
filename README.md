## About

AI Smart Learning Assistant is a beginner-friendly Python project designed to make learning easier and more interactive. It provides a simple GUI where students can learn topics, take quizzes, understand mistakes, check their performance, and create study plans.

## Features

- **Learn a Topic:** Simple explanations of different subjects.
- **Smart Quiz:** Subject-wise multiple-choice questions.
- **Mistake Explanation:** Explains incorrect answers.
- **Performance Report:** Shows marks and percentage.
- **Study Plan:** Provides subject-based study plans.
- **GUI:** Professional Blue and White theme with custom popups.
